Acknowledgments

I used AI throughout this book. I would not have attempted it without those tools. The manuscript grew in a GitHub repository, in conversation with Claude Code and Cursor.

I consider myself a software developer, not an author. The tools let me write the book I wanted.

I am grateful to my human reviewers, David Whipp, Apurva Gaikwad, and Audrey Yang, who read as the book was coming together.

This book started as a game of the same name that I made a few months earlier (https://into-the-singularity.barrybecker4.org/). William Keese gave me a lot of useful feedback for the game, even though he didn’t like playing it.
