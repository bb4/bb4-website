FAQ

Do I need to install anything?

No. These are multiplayer browser games. Open a game link, create or join a room, and play in a modern desktop or mobile browser.

How do I play with friends?

Start a game, then share the room link or invite code with the people you want to play with. Most titles support several players in one session.

Which games work well on phones?

Cards marked with the phone icon are especially comfortable on mobile. All of the games still run on any device with a modern browser.

What technology are these built with?

They are built with Svelte and hosted on Cloudflare. Real-time and turn-based multiplayer are handled in the browser over the network.

Where can I see trailers or usage stats?

Gameplay videos are on the YouTube channel. Aggregate play stats are on the usage stats dashboard.
